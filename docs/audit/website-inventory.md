## 2. Legacy Technical Assets & Dependencies

- **Web Server:** Microsoft-IIS / ASP.NET (.aspx routing)
- **CMS / Database:** Legacy custom ASP.NET WebForms backend with SQL Server / Access DB
- **Styles & Scripts:** Legacy jQuery 1.x, unbundled inline CSS, render-blocking scripts
- **Document Hosting:** Direct IIS static file serving for PDF notices and forms
- **Analytics:** Basic Google Universal Analytics tag (deprecated)
- **Mobile Friendliness:** Poor viewport adaptation; table-based layout fragments
